# L0C0 Oy

L0C0 Oy is a student restaurant web application that helps students find student restaurants in Finland and view their daily and weekly menus.

## Live Website

https://sujalmalakar.github.io/L0C0-Oy/

## Features

- View student restaurants in Finland
- Search restaurants by name or city
- Filter restaurants by city
- Filter restaurants by company
- View daily menus
- View weekly menus
- Register a user account
- Log in and log out
- View and update profile information
- Upload a profile picture
- Save favorite restaurants
- Filter favorite restaurants
- View restaurants on a map
- Find the nearest restaurant using device location
- Responsive design for desktop and mobile devices

## Technologies

- HTML
- CSS
- Vanilla JavaScript
- REST API
- Local Storage
- Geolocation API
- OpenStreetMap

## API

Restaurant, menu and user information is retrieved using the Metropolia Student Restaurants REST API.

https://media2.edu.metropolia.fi/restaurant/

## Running the Project

The application can be opened directly from the live website.

For local development, clone the repository and open the project using a local development server such as VS Code Live Server.
