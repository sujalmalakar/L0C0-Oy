# L0C0 Oy

L0C0 Oy is a student restaurant web application that displays student
restaurants in Finland and their menus.

## Features

- View student restaurants
- Search restaurants by name or city
- Filter restaurants by city
- Filter restaurants by company
- View daily menus
- View weekly menus
- Responsive design for mobile devices

## Technologies

- HTML
- CSS
- JavaScript
- Metropolia Student Restaurants API

## API

Restaurant and menu information is retrieved from the Metropolia
Student Restaurants API.
